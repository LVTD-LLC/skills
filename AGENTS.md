# Repository Instructions

## Source Of Truth

- Author skills in `skills/<skill-name>/`.
- Every skill must have `skills/<skill-name>/SKILL.md`.
- Do not hand-edit `.claude-plugin/`, `.agents/`, or `plugins/`. They are generated marketplace artifacts.
- `dist/registry.json` is generated by `npm run build` and is intentionally ignored.

## Adding Or Updating A Skill

1. Use a lowercase hyphen-case directory name, for example `skills/django-htmx/`.
2. Keep `SKILL.md` frontmatter complete:

   ```yaml
   ---
   name: django-htmx
   description: Build and review HTMX interactions in Django server-rendered projects.
   license: MIT
   compatibility: Codex, Claude Code, and other Agent Skills-compatible clients.
   metadata:
     version: "0.1.0"
     displayName: Django HTMX
     category: Web Development
     tags: django,htmx,server-rendered-ui
   ---
   ```

3. Put large examples, fixtures, or scripts under the same skill directory.
4. If a skill includes `scripts/`, make executable script files executable.
5. Run `npm run check` before finishing.
6. Commit source skill changes together with regenerated marketplace artifacts.

## Validation Commands

```bash
npm run validate
npm run build
npm run validate:marketplaces
npm run check
```

Use `npm run check` as the default final command. It validates skills, rebuilds registry and marketplace artifacts, validates generated marketplace files against source skills, and fails if committed generated artifacts are stale.
