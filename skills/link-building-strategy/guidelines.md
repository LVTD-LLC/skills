# Link Building Strategy Guidelines

Load the minimum files needed for the task.

## By Task

| What you're doing | Load these files |
|-------------------|------------------|
| Designing a full link-building campaign | `references/core/knowledge.md`, `references/core/rules.md`, `workflows/design-link-building-campaign.md` |
| Choosing between tactics | `references/core/knowledge.md`, `references/core/examples.md` |
| Defining metrics or ROI | `references/core/rules.md`, `workflows/design-link-building-campaign.md` |
| Reviewing an existing campaign plan | `references/core/rules.md`, `references/core/examples.md` |
| Explaining why link building needs assets and strategy | `references/core/knowledge.md` |

## By Problem

| If you notice... | Load these files |
|------------------|------------------|
| The plan says only "get more links" | `references/core/rules.md` |
| Tactics were chosen before assets or audiences | `references/core/knowledge.md`, `workflows/design-link-building-campaign.md` |
| Metrics are only link count or rankings | `references/core/rules.md` |
| The campaign depends on a vendor's private process | `references/core/knowledge.md` |
| The content idea serves buyers but not linkers | `references/core/examples.md` |

## Decision Tree

```text
What is the user asking for?
|
+-- Full campaign plan -> design-link-building-campaign workflow
+-- Pick tactics -> knowledge + examples
+-- Critique a campaign -> rules + examples
+-- Need asset ideas -> prefer linkable-asset-planning skill
+-- Need prospects -> prefer link-prospecting-research skill
+-- Need outreach -> prefer link-outreach-acquisition skill
```
