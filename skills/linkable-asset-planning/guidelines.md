# Linkable Asset Planning Guidelines

Load the minimum files needed for the task.

## By Task

| What you're doing | Load these files |
|-------------------|------------------|
| Planning new linkable assets | `references/core/knowledge.md`, `references/core/rules.md`, `workflows/plan-linkable-asset.md` |
| Auditing existing assets | `references/core/rules.md`, `workflows/plan-linkable-asset.md` |
| Turning market pains into content | `references/core/knowledge.md`, `references/core/examples.md` |
| Reviewing competitor linkable assets | `references/core/knowledge.md`, `workflows/plan-linkable-asset.md` |
| Choosing asset formats | `references/core/examples.md` |

## By Problem

| If you notice... | Load these files |
|------------------|------------------|
| The idea is just a sales page | `references/core/rules.md`, `references/core/examples.md` |
| The user wants backlinks but has no asset | `workflows/plan-linkable-asset.md` |
| The asset does not serve a linker audience | `references/core/knowledge.md` |
| A resource list adds no new value | `references/core/rules.md` |
| Competitors have linkable pages the user has not analyzed | `workflows/plan-linkable-asset.md` |

## Decision Tree

```text
What is the user asking for?
|
+-- New asset ideas -> plan-linkable-asset workflow
+-- Audit existing assets -> rules + workflow
+-- Choose format -> examples
+-- Need campaign strategy -> prefer link-building-strategy skill
+-- Need prospects for an asset -> prefer link-prospecting-research skill
```
