# Developer Docs Drafting Guidelines

Load the minimum files needed for the task.

## By Task

| What you're doing | Load these files |
|-------------------|------------------|
| Drafting a complete page | `references/core/knowledge.md`, `references/core/rules.md`, `workflows/draft-developer-doc.md` |
| Improving titles, headings, or outline | `references/core/rules.md`, `references/core/examples.md` |
| Writing procedures or task steps | `references/core/knowledge.md`, `references/core/rules.md` |
| Making a draft more skimmable | `references/core/rules.md`, `references/core/examples.md` |
| Creating a reusable doc template | `references/core/knowledge.md`, `references/core/examples.md` |

## By Problem

| If you notice... | Load these files |
|------------------|------------------|
| The title describes a feature instead of a user goal | `references/core/rules.md` |
| The doc starts with background before the task | `references/core/rules.md` |
| Steps contain multiple actions or no expected result | `references/core/knowledge.md` |
| Callouts are overused or carry required information | `references/core/rules.md` |
