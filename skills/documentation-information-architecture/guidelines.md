# Documentation Information Architecture Guidelines

Load the minimum files needed for the task.

## By Task

| What you're doing | Load these files |
|-------------------|------------------|
| Auditing a docs site or section | `references/core/knowledge.md`, `references/core/rules.md`, `workflows/audit-doc-ia.md` |
| Designing navigation or landing pages | `references/core/knowledge.md`, `references/core/examples.md` |
| Running content inventory | `references/core/rules.md`, `workflows/audit-doc-ia.md` |
| Planning migration or redirects | `references/core/rules.md`, `references/core/examples.md` |
| Improving findability | `references/core/knowledge.md`, `references/core/rules.md` |

## By Problem

| If you notice... | Load these files |
|------------------|------------------|
| Users cannot tell where to start | `references/core/knowledge.md`, `references/core/examples.md` |
| Navigation mirrors org chart or code architecture | `references/core/rules.md` |
| Content is duplicated across many pages | `workflows/audit-doc-ia.md` |
| Migration plan has no redirect or metadata strategy | `references/core/rules.md` |

## File Index

| File | Purpose |
