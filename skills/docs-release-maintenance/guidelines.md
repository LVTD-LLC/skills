# Docs Release Maintenance Guidelines

Load the minimum files needed for the task.

## By Task

| What you're doing | Load these files |
|-------------------|------------------|
| Planning docs for a software release | `references/core/knowledge.md`, `references/core/rules.md`, `workflows/plan-doc-release-maintenance.md` |
| Creating a publishing checklist | `references/core/rules.md`, `references/core/examples.md` |
| Assigning docs ownership or freshness checks | `references/core/knowledge.md`, `references/core/rules.md` |
| Setting up maintenance automation | `references/core/rules.md` |
| Deprecating or deleting docs | `references/core/knowledge.md`, `references/core/examples.md`, `workflows/plan-doc-release-maintenance.md` |

## By Problem

| If you notice... | Load these files |
|------------------|------------------|
| Docs are planned after code freeze | `references/core/rules.md` |
| Release notes omit user impact or required action | `references/core/examples.md` |
| No owner exists for high-risk docs | `references/core/knowledge.md` |
| The team wants to delete stale docs without redirects | `workflows/plan-doc-release-maintenance.md` |
