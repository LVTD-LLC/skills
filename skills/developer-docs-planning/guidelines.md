# Developer Docs Planning Guidelines

Load the minimum files needed for the task.

## By Task

| What you're doing | Load these files |
|-------------------|------------------|
| Creating a full documentation plan | `references/core/knowledge.md`, `references/core/rules.md`, `workflows/create-doc-plan.md` |
| Choosing content types | `references/core/knowledge.md`, `references/core/rules.md` |
| Planning API or reference docs | `references/core/knowledge.md`, `references/core/examples.md` |
| Planning release notes or changelogs | `references/core/knowledge.md`, `references/core/examples.md` |
| Reviewing a proposed doc outline | `references/core/rules.md` |

## By Problem

| If you notice... | Load these files |
|------------------|------------------|
| The plan says "write docs" with no doc types | `references/core/knowledge.md` |
| One doc tries to onboard, explain, reference, and troubleshoot | `references/core/rules.md` |
| The README is expected to do all documentation work | `references/core/knowledge.md`, `references/core/examples.md` |
| No source of truth is assigned for API details | `workflows/create-doc-plan.md` |
